YoniTube - local server + browser extension

How to use:
1. Run YoniTube_Server.exe (or server.py)
2. Load the extension from the "תוסף משולב" folder as an unpacked extension in Chrome/Edge.
3. Click the extension icon and download videos/audio/thumbnails.

The server provides:
- /download
- /cancel
- /kill_all
- /list_playlist
- /channel_info
- /watch_check
- /status
- /history
- /update_cookies
- /shutdown
